# 桌面与 Web 请求差异

**症状：**同一操作在 Tauri 正常、在浏览器失败，或收到未知命令、404、参数不匹配。

**根因：**前端调用经过 `src/utils/request.ts` 分流；Tauri 注册、Web 路由、输入或返回结构未同步，或者当前环境没有该原生能力。

**处理：**用合成数据核对请求名和输入形态；分别检查 `src-tauri/src/lib.rs` 的命令注册和 `src-tauri/src/proxy/server.rs` 的 HTTP 路由。原生能力明确提示不可用，不静默吞错，不关闭鉴权。

**预防：**改跨层接口时分别验证桌面和 Web 中受支持的路径、失败状态及错误文案。

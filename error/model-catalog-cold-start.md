# 冷启动模型列表仍显示思考档位

**症状：**「启用模型」里，内置的 Flash、Claude 已合并，但 Hydrogen、Neon 等账号模型的 `-low`、`-high`、`-xhigh` 仍单独显示；GPT OSS 出现基础名和 `-medium` 两项。

**根因：**冷启动时账号缓存可以先于内存官方目录载入。按官方目录成员判断能否聚合，会漏掉已经在可用列表里的档位；把“至少两个档位”当成必要条件也会漏掉 GPT OSS 的基础名与唯一变体。

**处理：**从当前可用列表匹配基础名与档位名，不要求内存官方目录已经同步。新版本会忽略旧的分组缓存，不需要清配置。具名档位仍能按原白名单调用，`-tiered` 保持为独立入口。

**预防：**回归测试从临时账号配额文件冷启动，不先填充内存官方目录；同时验证聚合后的基础名可以按请求档位路由。

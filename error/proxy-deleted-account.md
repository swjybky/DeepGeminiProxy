# 删除账号后网关继续使用旧账号

## 症状

从反重力账号池中移除旧账号后，原会话的新请求仍使用旧凭据，或账号在后台配额刷新结束后重新出现。

## 根因

配额刷新曾按邮箱更新账号。若删除先完成，旧刷新会重新创建账号，或覆盖同邮箱重新授权后的凭据。并发重载还可能晚于较新的重载应用旧账号池快照。

## 处理

配额刷新按原账号 ID 写回，确认索引和凭据文件仍对应这次刷新。完整重载和单账号重载按顺序执行，移除账号时清理其会话和固定账号绑定。

## 预防

在临时数据目录中保留删除前的账号快照，删除后导入新账号，再模拟旧刷新写回。使用同一个会话发起新请求，验证网关选中新账号；用同邮箱重新授权覆盖凭据更新场景。
